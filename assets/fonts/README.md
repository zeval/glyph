# Font Assets

glyph bundles Atkinson Hyperlegible Next Regular as its reader UI font.

## Bundled Font

- Family: Atkinson Hyperlegible Next
- File: `AtkinsonHyperlegibleNext-Regular.ttf`
- Format: static TrueType font
- License: SIL Open Font License 1.1, kept in `OFL.txt`
- Copyright: Copyright 2020-2024 The Atkinson Hyperlegible Next Project Authors

Atkinson Hyperlegible Next was selected because Braille Institute recommends it
for everyday readers, and its Regular TTF renders predictably through
SDL2_ttf/FreeType on PSP.
