# PSP Runtime Assets

`ICON0.PNG` is generated by `tools/dev/generate_psp_icon.py` from
`assets/branding/glyph-mark.png`.

The PSP menu icon is 144x80 RGB PNG with an opaque white background. Keep that
aspect ratio when replacing it so the XMB does not stretch the image. The
artwork should stay as the centered square glyph mark on the white backdrop.
