# Artwork

This directory contains original source artwork for `glyph`.

## Logo Concept

- Source: `logo-concept.html`
- Style: modern, technical lowercase `g`
- Palette anchor: app cyan `#62a4a8` on dark reader colors
- Intended exports: square app icon, README/social preview, PSP package artwork

The HTML file is the editable concept source. Open it in a browser to inspect
the inline SVG, small-size previews, and palette notes.
